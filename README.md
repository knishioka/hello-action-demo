# hello-action-demo

A throwaway repository for a YouTube short about GitHub Actions tags.

- `action.yml` is a tiny composite action.
- The `v1` tag is moved on purpose in the video to show that `uses: …@v1` can run different code without the workflow changing.
- The "changed" commit only prints a fake value (`DEMO_TOKEN=not-a-real-secret`). No real secret exists in this repository.

Do not use this action.
